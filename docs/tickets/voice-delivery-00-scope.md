## 明确不做（防范围漂移，写进 ADR 才算数）
换送达通道（系统通知 / 推送 / 播客）· 多设备并发（调 `--num-pipelines`，先测首音退化再议）·
登录凭据与强制 TLS（等给家人用）· 说话人识别 · 把 s2s 换成 OpenAI Realtime / LiveKit / Pipecat
（保留双层桥）· 密集进度播报 · 迁移旧 localStorage 通话记录（就地过期）。
