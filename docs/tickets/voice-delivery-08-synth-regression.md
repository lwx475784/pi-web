# 08 · 20 条合成语音自动回归（宣布"生产可用"的门槛）

**问题**：ADR 第 11 条要求错配率 <5 %，但真机人工念 20 条不可重复，也没法当基线。

**做法**：用 win 上的 `voice-gen` 合成 20 条语音（含撞车、超 2 分钟长任务、旁人插话、
跨设备接管），脚本直连 s2s WS 灌进 ASR，采集每条的实际播报与 requestId 配对结果，
自动产出 P50/P90（说完→首音）与 已播 / 错配 / 待读 三类矩阵。

**落点**：新增 `e2e/voice-delivery.mjs`（与现有 `e2e/run.mjs` 同层）、结果写 markdown 报告

**验收**：一条命令跑完出矩阵；连跑两次数字可复现；错配 <5 %；
合成音测不到的误唤醒率改由一周真实日志统计。

**估时**：1–2 人日 · **依赖**：01、02、03
